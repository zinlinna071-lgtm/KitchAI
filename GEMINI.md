# KitchAI instructions for Gemini

Read and follow the repository-root `AGENTS.md` before every task. These are mandatory project rules.

Preserve working behavior first. Diagnose root cause before edits; keep changes minimal on a non-`main` branch; add regression tests; run checks and report only actual results; never hide a failure by weakening tests; protect data, sync, security, offline/PWA and service-worker behavior; and stop to isolate/revert any regression. Do not merge before required checks and acceptance tests pass.

Use the full checklist and completion-report template in `AGENTS.md`.
