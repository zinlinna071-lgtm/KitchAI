# KitchAI v1.0.1 — Preview candidate

Status: **Preview candidate only — not released**

Baseline: approved KitchAI UI v1.0.0 on `main`.

## Scope

- Add a compact current-business name and switch icon to the Manage Mode top bar.
- Open a business list from the top bar; select an active business or create a new one from that list.
- Add a Business Profile page reachable from Manage Mode navigation.
- Support editing business name, type, phone, address, description, currency, time zone, and measurement units.
- Support archiving and restoring business profiles, while keeping at least one active business.
- Store preview business profiles locally in the current browser. This is a UI/workflow preview; cloud sync, account access, and business-data isolation for the full production modules are not claimed as implemented.
- Preserve the approved v1.0.0 production UI until the user reviews and approves the preview.

## Versioning and deployment rule

This branch targets the **v1.0.1** update. Do not merge into `main` or deploy to the production alias until the user has reviewed the Preview Deployment and approved it. Batch the work and use one preview deployment after the feature scope and checks are complete.

## Review checklist

- [ ] Manage Mode top bar shows only the current business name and switch icon.
- [ ] Business list opens from the top bar and includes “Create new business”.
- [ ] Create, switch, edit, archive, and restore flows work and survive refresh.
- [ ] Business Profile form is responsive on phone and desktop.
- [ ] Language/theme/navigation still work.
- [ ] Automated checks and production build pass.
- [ ] User approves before merge/release.
