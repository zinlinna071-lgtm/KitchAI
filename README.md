# KitchAI

KitchAI is planned as an offline-first web/PWA for kitchen and food-business operations, with a path toward reliable local–cloud sync and later AI-assisted workflows.

- [Work package registry](docs/WP_REGISTRY.md) — bounded tasks, dependencies, and completion evidence.
- [Decision log](docs/DECISIONS.md) — accepted planning constraints and open owner decisions.
- [Architecture options](docs/ARCHITECTURE_OPTIONS.md) — initial comparison; no provider has been selected.
- [Project status](docs/STATUS.md) — current milestone and work-package progress.

## Current status

Planning is in progress. No cloud provider or application stack has been selected yet; the architecture options must be compared before implementation dependencies are added. See the project status and decision log for the current state.
